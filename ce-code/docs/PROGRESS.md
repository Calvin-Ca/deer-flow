### 一条贯穿性教训

本轮多数 bug 属**同一类型：程序正常结束、指标看似正常、内容却是错的**——
条文库抓成条文说明、缺 API key 被 `except` 吞掉、思考模式没关、金标未回锚、判官副本没跟着换代。
这类问题靠人肉抽查发现不了，只能靠**断言**。故本轮新增的防线均为可证伪的硬指标：
表格捕获率 = 100%、切分渗漏 = 0、说明混入 = 0、路径错 = 0、金标必须回查条文、
判官全失败即中止、金标覆盖率随运行打印。
