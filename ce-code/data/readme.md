# CostAgent 知识库文件清单（广东 · 2024 标准版）

> 落地地区：**广东省**（以地级市为价格信息口径，示例用广州；深圳为独立体系另见注）。
> 标准时点：截至 2026-06，国家已启用 **2024 版清单计价/计算标准**（GB/T 系列），原 2013 版规范已废止。
> 优先级：**P0** = 单地区·房建 MVP 必备；**P1** = 扩展；**P2** = 增强。
> ⚠️ 定额、价格信息、图集多为版权资产，需正规采购/授权。

---

## ⭐ 重要前提：三套计价体系的版本错位（必须在系统层处理）

| 层 | 现状 | 影响 |
|---|---|---|
| 国家清单计价/计算标准 | **2024 版（GB/T）**，2025-09-01 起实施 | 清单编码、计量与计算规则按新标准 |
| 广东省综合定额 | **2018 版**（基于 2013 老规范编制） | 定额子目的工程量计算口径仍是老口径 |
| 广东省衔接文件 | 2025 计价规则调整 + 实施公告 | 用于把 2018 定额对接到 2024 标准 |

**坑**：按 GB/T 50854-2024 算出的清单工程量，与广东 2018 定额子目的计算口径**可能不一致**。算量引擎与组价模块需分别记录「清单计算规则版本」和「定额计算规则版本」，套定额时做口径对齐，否则量价错配。

## A. 清单与计量标准库 → 关系库 + 向量库（已更新为 2024 版）

| 文件 | 用途 | 入库 | 优先级 |
|---|---|---|---|
| **GB/T 50500-2024《建设工程工程量清单计价标准》** | 计价总规则、费用构成、清单编制（替代 GB50500-2013） | 关系库+向量库 | **P0** |
| **GB/T 50854-2024《房屋建筑与装饰工程工程量计算标准》** | 房建装饰清单编码 + 计算规则 + 特征项（MVP 主体） | 关系库+向量库 | **P0** |
| 广东省住建厅《实施 GB/T50500-2024 及 9 本计算标准》公告 + 粤建市〔2025〕196号 | 新标准在广东的落地口径与表格调整 | 关系库 | **P0** |
| GB/T 50856-2024《通用安装工程工程量计算标准》 | 安装专业 | 关系库+向量库 | P1 |
| GB/T 50857-2024《市政工程工程量计算标准》 | 市政专业 | 关系库+向量库 | P2 |
| GB/T 50855 / 50858~50862-2024（仿古/园林/矿山/构筑物/轨交/爆破计算标准） | 其余专业 | 关系库+向量库 | P2 |

> 注：2024 版由「规范(GB·强制)」改为「标准(GB/T·推荐)」，理论上当事人可自主决定是否采用，但广东已发文要求落地执行，按现行省口径处理。

## B. 定额库 → 关系库 + 知识图谱（广东 2018 综合定额）

广东省现行计价依据框架为 **《广东省建设工程计价依据（2018）》（粤建市〔2019〕6号，2019-03-01 起实施）**，下含各专业综合定额。

| 文件 | 用途 | 入库 | 优先级 |
|---|---|---|---|
| **《广东省房屋建筑与装饰工程综合定额（2018）》（上/中/下册）** | 清单→定额子目、人材机含量、基价（MVP 核心） | 关系库+KG | **P0** |
| **定额章节说明 + 工程量计算规则**（随定额发布） | 套用口径、扣减细则、附录（预拌混凝土/砂浆价格参考表、管理费分摊费率等） | 关系库+向量库 | **P0** |
| **《广东省建设工程施工机具台班费用编制规则（2018）》** | 机械台班单价编制 | 关系库 | **P0** |
| 《广东省建设工程计价依据（2018）》总则/费用相关规定 | 费用计取（管理费/利润/规费/税金口径） | 关系库 | **P0** |
| 计价依据（2018）勘误（粤标定函〔2019〕163号 等） | 子目/数据修正 | 关系库 | **P0** |
| 综合定额动态调整 / 补充子目文件（持续发布，如脚手架金属防护网等） | 新增/调整子目 | 关系库+KG | **P0** |
| **《关于调整〈广东省建设工程计价依据2018〉计价规则的通知》（2025-09-01 实施）** | 对接 2024 标准的计价程序、措施费规则调整 | 关系库（规则） | **P0** |
| 广东《通用安装 / 市政 / 园林绿化工程综合定额（2018）》 | 扩展专业 | 关系库+KG | P1/P2 |

> ⚠️ **深圳例外**：深圳为计划单列、独立计价体系（如 SJG 系列消耗量定额：《深圳市装饰工程消耗量定额》等）。若项目落地深圳，B 类需整套替换为深圳消耗量定额与深圳计价规则，不能套用广东省定额。

## C. 价格库 → 关系库（广东按地级市·月度发布）

广东价格信息**不是省级统一一本**，而是各地级市造价管理站按月发布。示例用广州：

| 文件 | 用途 | 入库 | 优先级 |
|---|---|---|---|
| **落地城市《建设工程人工、材料、施工机具价格信息》（月度）** | 当期人材机信息价（如广州市建设工程造价管理站逐月发布，文号穗建造价〔YYYY〕XXX号） | 关系库（带期号/effective_period） | **P0** |
| **落地城市建设工程常用材料税前综合价格（月度）** | 主材价格基准（注意「税前综合价/税后综合价」区分） | 关系库 | **P0** |
| 广东省工程造价信息化平台（gdcost.com）数据 | 省级汇总/校核 | 关系库 | **P0** |
| 材料价格指数 / 价格走势 / 调差文件 | 跨期调差 | 关系库 | P1 |
| 缺项处理规则（信息价缺项→珠三角其他 8 市造价信息取平均价） | 价格兜底逻辑（写入组价规则，非文件） | 规则配置 | **P0** |

> 价格库设计要点：每条价格必须带 `city + 期号 + 税前/税后` 三个维度，组价时按合同约定的计价口径取数。

## 采集与合规注意

- **版本时点**：A 类用 2024 版（2013 版已废止，仅历史项目对标时留存参考）。
- **地区一致性**：定额、机具台班、价格信息、计价规则必须同属广东省（且价格信息同一城市）；深圳项目整套换深圳体系。
- **版权授权**：定额、价格信息、图集需正规购买/授权。
- **格式优先级**：电子定额库 / Excel（结构化）> 文字版 PDF > 扫描件（需 OCR）。
- **持续更新**：价格信息按月、定额动态调整与计价规则文件不定期，需建立订阅式更新机制。
