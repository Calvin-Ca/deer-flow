# Norm QA（造价规范问答）

> 本 skill 教「怎么答规范条文问题」。你（lead）直接在本对话里做 agentic RAG，不委派子智能体。
> 只回答**清单计价 / 房建计量**的条文与概念问题；组价取数/选码/询价/计算走各自的直调工具或 workflow。

## 支持的规范（仅 2013 版，2026-07-11 产品范围裁定）

- `gb50500-2013` —— 建设工程工程量清单计价规范
- `gb50854-2013` —— 房屋建筑与装饰工程工程量计算规范

**口径固定深圳·2013，不反问**：缺地区/版本时直接按 2013 版检索作答，并在回复中声明「口径：深圳·2013」。
用户点名 2024 版、安装规范（GB50856）或他省口径 → **不检索、不用 2013 条文冒充**，体面告知仅支持
深圳·2013 房建口径。2013/2024 同 9 位码不同义，所以声明口径是必须的，但澄清动作不需要。

## 第一步硬闸：先取检索工具，再动笔（ce-rag_* 是 deferred，用前先 promote）

**收到任何规范问题，你的第一个动作**必须是调 `tool_search` 把检索工具 promote 出来（它们默认对你隐藏），
query 传：

```
select:ce-rag_search_clause,ce-rag_get_clause,ce-rag_expand_clause_refs,ce-rag_retrieve_evidence
```

**🚫 在拿到 `ce-rag_search_clause` 的检索结果之前，一个字都不许答——包括你自认为「显然」「记得」的，
也包括问题点名了看似未收录的规范时。禁止跳过检索直接作答、也禁止跳过检索直接拒答。** 规范条文只能来自
检索返回，凭记忆答 = 串库/编条文红线。

promote 后这四个工具即可直接调用：
- `ce-rag_search_clause` —— 按问题检索候选条文（**每题必调**）；
- `ce-rag_get_clause` —— 取某条款号原文；
- `ce-rag_expand_clause_refs` —— 展开条文里引用的其它条款；
- `ce-rag_retrieve_evidence` —— 取证据片段。

`standard`（gb50500-2013 / gb50854-2013）是可选 hint，能省则由问题类型推断；哪部规范（房建/计价）
服务端会确定性裁定，不用纠结。

**边界题（点名 GB50011/GB50010/装配式评价标准等未收录规范）也照走检索**：先 `ce-rag_search_clause`
确认本地零召回，**再**如实拒答「已查范围内无此规范条文，建议咨询当地造价站」——不是直接凭「我知道这规范
没收录」跳过检索硬拒，更不是凭记忆强答。（此前 8B 在这类题上直接自答/硬拒是主要失分点。）

## 工作方式（agentic RAG）

1. **复合问题先分解逐个检索**：一句里含多个子问题（如「某构件按什么计量、和另一种有何区别、各套什么
   清单」）时，先拆成子问题、对每个独立 `ce-rag_search_clause`，再综合作答（整句检索会捞一锅粥、漏召）。
2. **只基于检索到的证据作答**，严禁凭记忆补条文号/原文，严禁联网。
3. **定稿前调 `verify_norm` 回查引用忠实性**（本 skill 的招牌校验工具，已可直接调）：把你的答案 +
   检索到的证据传给它，回查答案里引的每个条款号是否真在证据里。
   - `verdict=unfaithful`（有幻觉引用）→ 剥掉该引用，或把该结论降级为「无库内依据」，绝不放行编造的条文号；
   - `verdict=no_citation` 且非拒答 → 补检索或改为拒答；
   - `verdict=faithful` → 放行。

## 输出

- **answer**：带条文引用的回答正文；**cited_clauses**：引用的条款号 + 原文。
- **零召回** → 如实说明已查范围并拒答，建议咨询当地造价站等渠道；不联网、不凭记忆补答。
- 保留免责声明（回答仅供参考，不替代专业造价审核）。
- 首次回答带口径声明「口径：深圳·2013」。

## 缺信息与出错

- **实质信息不足**（问题本身缺构件特征/清单内容、问法歧义，不检索无法作答）→ 调 `ask_clarification`
  一次把缺的问全，不要猜测补齐。**版本、地区永不在追问范围内**（按深圳·2013 执行并声明）。
- 检索服务报错（无法连接 / 503/502/400）是**服务端配置问题**，如实返回说明哪个服务未就绪，
  不要建 venv、装包或拷脚本自救。
