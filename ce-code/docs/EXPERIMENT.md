### 为什么固定 step 而不是 epoch

四组数据量差 4 倍。若固定 3 个 epoch，A 组只见 2.4 万次样本，B 组见 9.6 万次 —— 效果差异会混入"计算量"因素，无法归因到数据质量。

固定 1500 步意味着四组消耗的计算量完全相同（相同 batch size 下），数据少的组会多循环几遍。

> **这个设计选择必须写进报告和简历。** 它是实验严谨性的直接体现，也是面试时的加分点。

### 已知局限（如实记录，不要掩盖）

1. 固定 step 下，A 组（8k 数据）会把数据循环约 15 遍，存在过拟合风险；B 组仅约 3.7 遍。这是固定 step 方案的固有代价。
   - **缓解**：记录各组训练 loss 曲线，若 A 组明显过拟合，在报告中说明并补一组"A 组早停"作为参考
2. 未做多 seed 重复实验（成本考虑）。单次结果存在随机性，指标差异 < 1.5pt 的结论应表述为"无显著差异"
3. B 组未做随机采样对照（不同于医疗方案中的 B 组，此处 B 是策略而非采样）

## 4. 结论撰写要点（跑完后按此组织）

**必须回答的四个问题**

1. **A → B 提升了多少？** 说明"把条文变成问答形式"这一步的价值。预期是最大的单步提升。
2. **B → C 的提升体现在哪个维度？** 关键洞察：质量过滤主要提升的可能是**可靠性指标**（条款引用 F1、幻觉率），而非准确率。如果是这样，这个发现比"准确率涨了"更有价值。
3. **C → D 是否在整体准确率上几乎持平？** 若是，必须指出：**只看整体分会得出"难样本无用"的错误结论**，分项统计才揭示它在跨条文（+Xpt）和拒答（+Xpt）上的贡献。这是自建分类评测集的价值证明。
4. **base_fewshot 表现如何？** 若它已接近 group_a，说明 A 组的构造方式确实低效；若远低于所有微调组，说明领域知识无法靠 prompt 补足。

**必须诚实报告的**
- 与预期相反的结果（例如某个过滤器没有带来提升）
- 未做多 seed 的局限
- 评测集规模有限（400 题）带来的置信区间

> 反直觉但有解释的结论 > 全线飘红的漂亮数字。前者面试能聊 30 分钟，后者聊 5 分钟就被问穿。

## 5. 可选扩展（时间富余才做）

| 扩展 | 成本 | 收益 |
|---|---|---|
| LoRA rank 消融（8/16/32/64） | 低（复用 D 组数据，4 次训练） | 简历多一条，且能答"为什么是 32" |
| 通用:垂域数据配比（1:0 / 1:1 / 1:3） | 中 | 直接对应"灾难性遗忘"高频面试题 |
| B 组多 seed 重复 | 中 | 补上 §1 局限 2 |
| 软幻觉的细粒度分析 | 低 | 报告深度 |

**优先级：rank 消融 > 数据配比 > 其他。** 前两个都是面试高频问题的答案载体。
