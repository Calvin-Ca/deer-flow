\[E_{\mathrm{c}}^{\mathrm{f}} = 0.00006f_{\mathrm{ck}} + 0.0003\]

其中，$f_{\mathrm{ck}}$ 是混凝土的立方体抗压强度标准值，单位为MPa。对于C50等级的混凝土，其立方体抗压强度标准值 $f_{\mathrm{ck}}$ 为50MPa。

将 $f_{\mathrm{ck}} = 50$ MPa 代入上述公式中，可以计算出C50混凝土的疲劳变形模量 $E_{\mathrm{c}}^{\mathrm{f}}$：

\[E_{\mathrm{c}}^{\mathrm{f}} = 0.00006 \times 50 + 0.0003 = 0.003 + 0.0003 = 0.0033\]

因此，C50混凝土的疲劳变形模量 $E_{\mathrm{c}}^{\mathrm{f}}$ 为0.0033 MPa^-1。
