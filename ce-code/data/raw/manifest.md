# 规范原始文件清单

> `raw/` 下只放**原始 PDF**（原件原名照搬，不改名、不处理）+ 本清单。
> 点文件名可直接打开对应 PDF。
> **PDF 不入 git**（版权敏感、文件大）；**本清单入 git**，作为已收录规范的溯源凭证。

## 用法约定

- 加规范 = 把 PDF 丢进 `raw/` + 在下表加一行。
- 链接用尖括号包路径 `[显示名](<带 空格(括号).pdf>)`，原件含空格/括号也能点开，无需改名。
- `角色`：`正文` / `条文说明` / `强条汇编` / `局部修订`
- `效力`：`active` / `superseded`（被新版取代）/ `abolished`（废止）。多版本共存靠此列区分，改版后新 PDF 标 `active`、旧的改 `superseded`。
- `standard_id` 为下游真值（02_extract_clauses 据此取，替代“按文件名猜”）；同一规范的多个 PDF 共用同一 `standard_id`。
