工程加固 & 评测（弱模型 8B 上的可靠性层）

② 复核 agentgenerator–verifier
cost-critic 对抗复核组价结果：cost_verify 确定性算术重算/串库/编码 + LLM 语义构件↔码。fail 打回、doubt 转人工。
⑤ agentic RAGnorm-qa
复合问题分解逐个检索 + norm_verify 引用条款号回查∈检索证据（治幻觉引用）。开关 CE_NORM_FAITHFULNESS_CHECK。
⑥ 主动学习few-shot·不训练
HITL 纠正入库 → 选码前 cost_recall_exemplars 检索相似历史纠正作 few-shot（按 spec 隔离）。
① 评测体系benchmark
纯函数打分器 + runner：cost_task(pass^k+红线) / norm_faithful(traditional↔agentic 对比)。Langfuse 挂分。任何加固过它防退化。
红线（贯穿所有 cost 流）：选码只在候选内、不造码，低置信转人工；算钱一律走确定性 Python，LLM 不算钱； 地区/版本严格隔离（默认深圳·2013）；无命中不杜撰。红线靠确定性护栏（cost_verify / norm_verify）enforced，不靠 prompt 祈祷。  已退役：ce-services :8101 任务层、前端组价 widget、13 节点独立 HITL 图 —— 组价编排现唯一路径为 harness 内嵌 cost_workflow_* + ce-rag/ce-db MCP。
