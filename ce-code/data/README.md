# 知识收录范围（数据资产清单）

> 本文为 `data/` 下数据资产的收录范围说明，内容同步自 `../PRD.md §4 知识收录范围`，**以 PRD 为准**；此处便于在数据目录就近查阅。

知识层是**算量组价的造价知识底座**，按"算量"与"组价"两个环节所需的知识组织。数据源不止 PDF：定额是消耗量标准，价格是定期更新的信息价，历史库是项目沉淀。

> **范围：广东省深圳市 · 房屋建筑专业。** 跑通后再扩地区 / 专业。
> **地区强隔离（硬约束）**：只收录、只召回**深圳本地标准**——深圳有独立的 2024 版消耗量标准，与省内其它城市口径不同，是最易串库的坑。
> **时效性入库即校验**：所有收录单元均为**现行有效**版本（国标 2024 版、深圳本地 2024 版均已实施），录入时核对实施状态，旧版本不入库——故下文"状态 / 实施日期"仅作溯源标注，检索侧无需再做废止过滤。

> `doc_id` 为知识库内部稳定标识（入库 / 检索 / 溯源引用以此为准），与标准编号解耦——标准编号可能改版或待补号，`doc_id` 不变。**效力优先级**承接下文元数据治理：深圳本地（消耗量 / 费率配套）= 1（最高），国标 = 4（最低，越具体越优先）；动态数据走独立更新管道，不参与口径优先级排序。标注"待补号"的消耗量标准编号待官方公布后回填，`doc_id` 与入库不受影响。

> **必要性分级**（针对深圳·现浇土建房建 MVP）：**⭐MVP** 属 §7 最小收录集，组价最小闭环缺一不可；**[必收]** 完整组价闭环需要；**[条件]** 仅特定项目/阶段需要（装配式、含机电等），非必收；**[可缓]** 完整造价需要但 MVP 阶段可后置。**[已收录]** 列标注服务器解析进度：✅ 已解析 / ⏳ 已下载待解析 / ❌ 未收录。

## 收录单元的元数据治理（强一致、可审计）
每个收录单元须携带，并作为检索过滤依据：

| 元数据 | 作用 |
|---|---|
| 版本 / 标准编号 | 标注版本（库内只保留现行有效版本，入库时校验） |
| 时效状态 | 库内单元均为**现行有效**；旧版本 / 废止不入库（时效性入库即校验，检索侧无需过滤） |
| 适用地区 | 支撑地区强隔离（深圳 ≠ 省内其它城市） |
| 适用专业 | 房建专业过滤 |
| 实施日期 | 记录实施时点，供溯源与版本核对 |
| **效力优先级（1~4）** | 口径冲突时排序取值：深圳本地 = 1（最高） → 国标 = 4（最低，越具体越优先） |
| 是否动态 + 更新频率 | 信息价（月更）走独立更新管道，与静态规范分离 |
