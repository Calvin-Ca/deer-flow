2. 三条主请求链路

A · 完整组价（HITL 主线）
用户消息 → lead_agent8B → 技能 cost.py start 或 /orchestrate → prerouter 判「完整组价形态」→ _ignite_hitl 只点火：session.start 跑图至首闸 → 返回 task_id + ```cost-hitl``` marker（刻意不回首闸内容）→ 前端识别 marker 升级为交互卡片 → 之后用户每次 submit：卡片 → /ce-cost 代理 → /cost/session/{id}/resume → 图内 interrupt() 返回用户决策 → gates 钉值 → 续跑到下一闸/done。逐闸交互全程零 LLM。
B · 一次性组价（简单场景旧路）
/cost/compose → bill_match（:8100 Milvus 召回 top-k）→ select_code32B（候选内选码 + cosine 校准置信 + 越界作废红线）→ price_compose（:8100 PG 取定额工料机+信息价）→ 可选确定性算综合单价 → 信封含 guard/caliber 元数据。选不出码→skipped(need_review)；2013 数据未就绪→501 如实透传。
C · 规范问答
/norm/qa（或 MCP norm_qa / 编排器子任务，三调用点共用 pipeline.answer_query 单一内核）→ resolve_standard确定性 → :8100/search 混合检索 → 零召回先联网兜底（三道确定性闸筛可信源）→ generation8B 带引用作答 → guards 校验闸（C-01/02/03）→ 结构化回答。

3. HITL 组价状态机（cost/graph.py 实际节点）

START → setup（缺版本默认深圳·2013，不反问，发 caliber 事件） ┌─────────────── 多构件外层循环（current_item 推进，闸只动当前件） ───────────────┐ │ list_matchLLM选码·compute → feature_gate缺特征停闸 ──补了特征──→ 回 list_match（≤2 轮） │ ↓ 特征齐 │ list_gate（τ 双阈值三段式：≥τ_high 自动过 / 中段停闸确认 / <τ_low 提示补描述） │ ├─ 选不出码 → skip ─────────────────────────────→ advance │ └─ 有码 → compose取数·compute → quota_gate（唯一子目自动过 / 多子目 32B 消歧或人选 / │ 缺映射→补录人材机基价或放弃）→ price_gate（缺价逐项录入，命中绝不问） │ → quantity_gate（缺 Q 必录，绝不按 1 计）→ advance └─ advance：还有件 → 回 list_match ；全办完 ┬→ 有可算件 → rates_gate └→ 全不可算 → no_pricing（blocked，不虚构总价）→ END rates_gate（费率政策数缺则停录）→ params_gate（税率必录）→ rollup_compute两级汇总·逐层发事件 → rollup（末尾 review 始终暂停）→ done → END 辅助：rewind（白名单闸回退）· recompute_rollup（what-if 纯函数重算，不落检查点）
工程要点：compute/gate 双拆（interrupt-resume 从节点头重跑，昂贵 LLM 调用放上游有 checkpoint 的 compute 节点，gate 幂等）；每节点发 provenance 事件；用户决策经 lock_value 钉死、下游只读。

6. 关键设计不变量（从代码注释与实现提炼）

不变量代码落点
编排权在代码，LLM 只在窄节点出候选、不决定是否跳闸gates.should_pause_* · graph 固定边 · orchestrator 固定三段
数字必须带结构化来源，前端只渲染结构化字段provenance 信封 · types.ts · gates.tsx
用户决策=权威锁定，resume 不重跑 LLMlock_value · compute/gate 双拆 · SqliteSaver checkpoint
不杜撰：缺价/缺费率/缺 Q/缺定额→停闸或 blocked，绝不补数no_pricing · missing_base/quantity · 501/404 如实透传
LLM 失败必有确定性降级，成对回落decompose/synthesize fallback · 32B URL+model 成对回落 · route fail-safe
版本口径隔离（2013/2024 同码不同义）SPEC_REGISTRY.resolve_spec · bill_match 必填 spec · 未就绪 501
