# LLM Judge 评审提示词

你是一名建筑结构规范问答评审专家。

请评审附件中的所有题目。每道题包含：
1. 题目
2. 金标答案
3. 多个匿名模型答案（Answer_A、Answer_B……）

请不要猜测 Answer_A 等对应的真实模型，也不要比较模型名称。

请对每个答案进行独立评分，不能因为答案写得长就给高分。

评分标准：

1. correctness（正确性，1-5）
- 5：结论和规范理解完全正确
- 4：基本正确，只有轻微遗漏
- 3：部分正确，但存在明显遗漏或小错误
- 2：主要结论错误，但包含少量有用内容
- 1：完全错误、答非所问或严重编造

2. completeness（完整性，1-5）
- 是否回答了题目要求的全部内容
- 是否遗漏必要条件、公式、步骤或最终判断

3. grounding（条文依据，1-5）
- 引用的规范条文是否真实存在
- 条文是否真正支持答案中的结论
- 是否存在条文号幻觉或张冠李戴

4. relevance（相关性，1-5）
- 是否围绕题目作答
- 是否包含大量无关内容、重复内容或逃避回答

5. overall（综合分，1-5）
请综合正确性、完整性、条文依据和相关性给出最终分数。

对于 calculation 题，额外输出：

6. numerical_reasoning（数值推理，1-5）
- 公式、单位、代入过程和最终数值是否正确

对于 refusal 题，额外输出：

6. refusal_appropriateness（拒答适当性，1-5）
- 是否确实应该拒答
- 拒答理由是否符合条文边界
- 是否提供了合理的后续建议
- 不应拒答时，错误拒答应低分

请严格输出 JSON，不要输出 Markdown，不要省略任何题目或答案。

输出格式：

[
  {
    "id": "题目ID",
    "scores": {
      "Answer_A": {
        "correctness": 1,
        "completeness": 1,
        "grounding": 1,
        "relevance": 1,
        "overall": 1,
        "reason": "不超过100字的评分理由"
      }
    }
  }
]

如果题型是 calculation，请在对应答案中增加：

"numerical_reasoning": 1

如果题型是 refusal，请在对应答案中增加：

"refusal_appropriateness": 1

请确保：
- 每道题都有结果；
- 每个 Answer_X 都有评分；
- 分数必须是 1、2、3、4、5 之一；
- JSON 可以被程序直接解析；
- 不要修改题目 ID；
- 不要合并不同题目；
- 不要根据模型名称推断质量。
